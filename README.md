# 🎮 Game Name

> 一款基于 `Godot Engine` 开发的**2D**下落式射击类游戏


---

## 📖 简介

**Vector Combat** 是一款以高速移动与射击为核心玩法的**2D**动作游戏。玩家需要利用冲刺、射击和移动技巧击败不断出现的敌人。

---

## 🎮 游戏特色

* ⚔️ 高速战斗
* 💨 流畅的移动与冲刺系统
* 🎯 射击与敌人系统
* 💥 爆炸与粒子效果
* 🎵 音效系统
* 📈 不断增加的游戏挑战

---

## 🕹️ 操作方式

| 按键           | 功能      |
| ------------  | -------   |
| `W` / `Space` | 向上移动   |
| `A` / `D`     | 左右移动   |
| `Left Mouse`  | 射击      |
| `Right Mouse` | 冲刺      |
